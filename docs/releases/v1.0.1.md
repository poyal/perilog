# 페리로그 v1.0.1

앱 이름은 **페리로그**, 설명은 **나의 하루, 나의 투석 기록**입니다. 파란 나비 리본 기록장 테마에 맞춰 화면을 다듬고 큰 편집 모달을 전용 화면으로 바꿨습니다.

- 오늘 할 일·완료 진행률, 어제 미작성 기록 이어 쓰기
- 고정 저장 버튼이 있는 품목·입고·재고·사용 구성 편집, 입력 복구와 변경 버리기 확인
- 설정과 재고에서 같은 사용 구성 관리, 품목별 EA 수량과 색상 표시
- 치료 카드 안에서 구성 바로 적용, 이번 기록의 수량만 별도로 수정
- 기록 화면의 리스트·캘린더·기간별 표, 7D·30D·직접 기간 조회
- 가로·큰 글씨·키보드 환경에서도 입력칸을 확보하는 배치
- 소수점 이어 입력하기와 수량 지우기 개선, 화면 이동 후 이전 저장 알림 제거
- 기본·큰 글씨·오프라인 자동 E2E와 실패 캡처, PR/main용 CI 추가

버전 코드는 2입니다. 앱 ID·서명 키·Room 스키마·백업 형식은 유지해 v1.0.0 위에 설치할 수 있습니다. 선택한 치료 날짜는 자정이나 아침 입력 때문에 자동으로 바뀌지 않습니다.

## 설치 파일

- `perilog-1.0.1.apk`: 동일 서명으로 만든 개인 설치용 APK, 약 4.9MiB
- `perilog-1.0.1.sha256`: APK와 스크린샷 ZIP 체크섬
- `perilog-1.0.1-screenshots.zip`: 신규 UI를 실제 실행한 에뮬레이터 화면 23장

기존 앱을 삭제하지 않고 새 APK를 설치하세요. 앱 삭제·기기 변경 전에는 설정에서 기록을 파일로 내보내세요.

[신규 UI 이미지 사용 매뉴얼](https://github.com/poyal/perilog/blob/v1.0.1/README.md)

## 검증

계산·저장소 검사 25개, 기본·큰 글씨 오프라인 E2E 각 15개 통과. Lint 오류 0. 프로세스 종료 후 미저장 입력 복구, 가로 키보드 입력칸 표시, v1.0.0 업데이트 전후 데이터 유지와 APK 서명을 확인했습니다.

캡처는 Android 16 / API 36 에뮬레이터의 예시 자료입니다. 실물 Z 플립7의 접기·펼치기, 삼성 파일 선택기·키보드, 절전 알림은 별도 확인 대상입니다. 자세한 [검증 기록](https://github.com/poyal/perilog/blob/v1.0.1/readme/검증-기록.md)과 [자동 E2E 실행 안내](https://github.com/poyal/perilog/blob/v1.0.1/readme/E2E-테스트.md)를 참고하세요.
