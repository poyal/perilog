# v1.0.10 변경 내용

## 설정을 한 목록에서 바로 열기

설정 첫 화면에 일반, 백업·데이터, 투석 기록·물품, 병원·연락처, 도움말·앱 정보 항목을 구역별로 펼쳤습니다. 중간 카테고리를 거치지 않고 원하는 설정으로 바로 들어갑니다. 저장 버튼은 상세 화면 아래에 고정되며, 저장 결과를 안내하고 저장 전 나갈 때 변경사항을 확인합니다. 완료 축하 애니메이션은 제거했습니다.

## 알림과 기록 입력

알림 허용·소리·진동은 Android 설정을 따르고 앱에서는 알림 시각을 정합니다. Android 13 이상에서는 첫 실행에 필요한 OS 알림 권한을 요청하며, 거절 후에는 시스템 설정에서 변경할 수 있습니다. Android 12는 시스템 알림 설정을 바로 사용합니다. 기존 앱 내부 알림 스위치 대신 OS 설정을 사용합니다.

기록의 사용 구성은 펼쳐진 버튼을 한 번 눌러 선택합니다. 이번 기록에서 직접 조정한 수량은 같은 구성 버튼을 다시 눌러도 유지됩니다. 피검사 등 병원 일정의 검사·치료 항목에도 시간을 지정하거나 해제할 수 있습니다.

## 위젯

어제·오늘 기록 위젯에 별도 2×2 기본 크기를 추가했습니다. 기존 4×2 위젯을 유지하면서 크기를 줄였을 때 바로 배치를 갱신하도록 수정했습니다. 앱 잠금 중에도 위젯 내용은 표시되며, 위젯을 눌러 앱으로 들어갈 때 인증합니다.

## 업데이트

기존 앱을 삭제하지 않고 같은 서명의 APK를 덮어 설치해 주세요. 설정 → 데이터 내보내기·가져오기에서 미리 전체 데이터를 보관할 수 있습니다. DB 스키마는 8을 유지하며, 이전 백업의 설정과 치료 항목을 읽습니다.

## 검증

이번 버전의 로컬 검사와 서명 APK 업데이트 보존 검증을 진행 중입니다. 실제 결과와 확인 범위는 게시 전에 [검증 기록](https://github.com/poyal/perilog/blob/main/docs/검증-기록.md)에 반영합니다.
