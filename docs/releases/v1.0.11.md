# v1.0.11 변경 내용

## 저장 알림 위치 개선

저장 결과를 상태 표시줄 아래에서 내려오는 상단 알림으로 표시합니다. 알림이 나타나거나 사라져도 본문과 취소·저장 버튼이 움직이지 않습니다. 기록 삭제 후 **되돌리기**도 상단 알림에서 사용할 수 있습니다. 큰 글씨·가로 화면·키보드 표시와 접근성 권장 표시 시간을 반영합니다.

## 설정 순서 조정

설정 목록은 **일반 → 투석 기록·물품 → 병원·연락처 → 백업·데이터 → 도움말·앱 정보** 순서입니다. 백업·데이터를 도움말 바로 위로 옮겼으며 각 메뉴의 기능은 그대로입니다.

## 업데이트

기존 앱을 삭제하지 않고 APK를 덮어 설치해 주세요. 업데이트 전에 **설정 → 데이터 내보내기·가져오기**에서 전체 데이터를 보관할 수 있습니다. DB 스키마는 8을 유지합니다.

## 검증

이번 버전의 로컬 검사와 서명 APK 설치·업데이트 보존 결과는 게시 전 [검증 기록](https://github.com/poyal/perilog/blob/main/docs/검증-기록.md)에 확정해 남깁니다.
