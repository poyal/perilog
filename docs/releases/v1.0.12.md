# v1.0.12 변경 내용

## 앱 잠금과 화면 보호를 따로 선택

**설정 → 앱 잠금·화면 보호**에서 두 옵션을 각각 저장할 수 있습니다. **앱 잠금**은 앱에 들어올 때 생체 인증 또는 기기 잠금을 확인합니다. **화면 보호**는 화면 캡처·녹화·공유와 최근 앱의 내용 노출을 제한합니다. 앱 잠금만 사용하면 인증 후 화면을 캡처할 수 있으며, 화면 보호만 켤 수도 있습니다.

기존에 앱 잠금을 사용하셨다면 업데이트 후에도 두 기능이 모두 켜져 보호 수준이 유지됩니다. 홈 화면 위젯과 외부에 저장한 백업 파일은 화면 보호의 대상에 포함되지 않습니다.

## 업데이트 다운로드 상태 수정

이전 버전의 다운로드 기록을 최신 APK로 잘못 표시하던 문제를 수정했습니다. 새 버전 안내가 표시되면 해당 버전의 다운로드 상태만 사용하며, 다운로드·재시도·설치 버튼에도 대상 버전을 표시합니다. 이전 다운로드나 검증 작업이 늦게 끝나더라도 새 버전의 상태를 덮어쓰지 않습니다.

APK의 앱 ID·버전·서명·체크섬 검증을 유지하며, 설치된 버전과 같은 파일이나 안내와 다른 버전의 파일은 원인을 구분해 안내합니다.

## 업데이트 방법

기존 앱을 삭제하지 않고 APK를 덮어 설치해 주세요. 업데이트 전에 **설정 → 데이터 내보내기·가져오기**에서 전체 데이터를 보관할 수 있습니다. DB 스키마는 8을 유지합니다.
