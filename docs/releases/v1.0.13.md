# v1.0.13 변경 내용

## 병원 일정 캘린더 연동

**설정 → 캘린더 연동 → 휴대폰 캘린더 연결**에서 일정을 보낼 캘린더를 선택할 수 있습니다. 페리로그에서 병원 예약을 등록·수정·삭제하면 연결된 캘린더에도 반영합니다. 첫 연결은 오늘 이후 예약을 보내며, 다른 앱에서 만든 일정은 변경하지 않습니다.

예약 메모는 기본으로 제외합니다. 복원한 예약은 기존 캘린더 일정을 확인한 후 다시 연결해 중복 전송을 방지해 주세요. 제목은 **병원 방문 · 신장내과 외 1개**처럼 짧게 표시하며 전체 진료·검사·치료 항목은 일정 설명에서 확인합니다.

현재는 **페리로그 → 캘린더 단방향 반영**입니다. 캘린더에서 수정·삭제한 내용을 페리로그로 가져오지 않습니다. 구글 직접 연결은 배포 서명에 맞는 OAuth 설정과 실제 계정 인증 확인이 남아 있으므로, 이번 버전에서는 휴대폰 캘린더 연결을 이용해 주세요.

## 버튼과 일정 화면 정리

텍스트만 표시하던 동작을 배경·테두리가 있는 작은 버튼으로 바꾸고 크기·여백·간격을 통일했습니다. 공간이 부족하면 버튼이 다음 줄로 배치됩니다.

홈에서 여는 일정 상세와 **설정 → 병원 일정**이 같은 예약 카드를 사용합니다. 카드 오른쪽 위 **⋮ 더보기**에서 수정·같은 구성으로 다음 예약·삭제를 선택합니다. 활력 상태는 **수정 아이콘**으로 입력을 펼치고 **저장 아이콘**으로 요약을 표시합니다. 입력값은 초안으로 보관되며 전체 기록은 화면 아래 **기록 저장**으로 저장합니다.

캘린더 선택의 가운데 정렬과 연결 확인창의 구역·간격도 정리했습니다.

## 업데이트 방법

기존 앱을 삭제하지 않고 APK를 덮어 설치해 주세요. 업데이트 전에 **설정 → 데이터 내보내기·가져오기**에서 전체 데이터를 보관할 수 있습니다. DB 스키마는 8에서 9로 올라갑니다.
