# v1.0.14 변경 내용

## 날짜 선택 버튼 개선

기록 추가·편집 화면의 날짜 버튼을 **어제 → 오늘 → 날짜 선택** 순서로 정리했습니다. 어제·오늘도 배경과 테두리가 있는 버튼으로 표시하고, 선택된 날짜는 채운 배경으로 강조합니다. 큰 글씨나 좁은 화면에서는 버튼이 다음 줄로 배치됩니다.

새 기록의 기본 날짜는 오늘입니다. 기존 기록·초안, **어제 기록하기**, 달력에서 선택한 날짜로 들어갈 때는 해당 날짜를 유지합니다. 날짜를 바꿀 때 작성 중인 입력값과 초안을 보존하는 동작도 유지합니다.

사용자 매뉴얼과 앱 안의 안내 화면을 변경된 버튼에 맞춰 갱신했습니다.

## 업데이트 방법

기존 앱을 삭제하지 않고 APK를 덮어 설치해 주세요. 업데이트 전에 **설정 → 데이터 내보내기·가져오기**에서 전체 데이터를 보관할 수 있습니다. DB 스키마는 9를 유지합니다.

## 검증

이번 후보의 로컬 검증 결과와 공개 파일 확인 결과는 검증 완료 후 기록합니다.
