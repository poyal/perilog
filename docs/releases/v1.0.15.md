# v1.0.15 변경 내용

## 기록 저장과 화면 이동

치료 기록과 추가투석은 **기록 저장**을 눌렀을 때만 저장합니다. 변경 후 뒤로가기·다른 탭·다른 위젯으로 이동하면 **계속 입력** 또는 **변경사항 버리고 나가기**를 선택합니다. 버리고 나가도 기존 기록과 재고는 유지합니다. 같은 기록의 위젯을 다시 누르면 작성 중인 입력을 유지합니다.

화면 회전과 도움말 왕복에도 입력을 유지합니다. 이전 버전에서 남은 초안은 이어서 저장하거나 명시적으로 삭제할 수 있습니다. 활력 상태의 저장 모양 아이콘은 **접기** 아이콘으로 바꿨습니다.

## 평균저류시간 선택

시간·분 직접 입력을 24시간 형식의 시계판으로 바꿨습니다. 선택 범위는 **0시간 00분~23시간 59분**입니다. **적용**은 입력 화면에만 반영하며, **취소**는 기존 값을 유지합니다. **시간 지우기**로 미입력 상태로 돌릴 수 있고, 미입력과 0분은 구분합니다. 이전 범위 초과값은 기록 수정 시 다시 선택하거나 지운 뒤 저장합니다.

혈압의 반대쪽 값이 자동으로 0이 되는 현상은 재현되지 않았습니다. 공통 숫자 입력은 변경하지 않고, 신규·저장 기록·기존 초안에서 반대쪽 빈칸과 명시적으로 입력한 0의 보존 검사를 추가했습니다.

## Android 지원과 안내

Android 11(API 30) 이상을 지원합니다. 이전 개발 변경의 Android 호환성·창 크기 대응·화면 보호 보완을 포함합니다. 사용자 매뉴얼과 앱 도움말을 새 저장 방식과 시간 선택 화면에 맞춰 갱신했습니다.

## 업데이트 방법

기존 앱을 삭제하지 않고 APK를 덮어 설치해 주세요. 업데이트 전에 **설정 → 데이터 내보내기·가져오기**에서 전체 데이터를 보관할 수 있습니다. DB 스키마는 9를 유지합니다.

## 검증

전체 단위·저장소 250개, API 35 기본·큰 글씨 각각 100개, API 36 입력 회귀 각각 7개를 통과했습니다. Lint 오류 0개, 실제 프로세스 종료 후 입력 복구, Android 11·12·15 서명 APK 신규 설치를 확인했습니다. 공개 1.0.14 덮어 설치에서 19개 테이블·37행·341개 필드와 재고·초안·백업·권한을 보존했습니다. 자세한 결과와 실기기 미검증 범위는 [검증 기록](../검증-기록.md)에 있습니다.
