# v1.0.16 변경 내용

## 평균저류시간 직접 입력

시계판 선택기를 이전처럼 **시간·분을 직접 입력하는 형태**로 바꿨습니다. 시간은 **0~23**, 분은 **0~59**의 최대 두 자리 숫자만 입력할 수 있습니다. 범위를 벗어난 숫자와 음수·소수·문자는 입력되지 않습니다.

한쪽 입력칸을 지워도 다른 쪽 값은 유지합니다. 한쪽만 입력하면 다른 단위는 0으로 계산하며, 두 칸을 모두 비우면 미입력으로 돌아갑니다. 직접 입력한 0분과 미입력은 구분합니다. 화면 회전과 도움말 왕복에도 입력을 유지하고 **기록 저장**을 눌러야 반영합니다. 이전 기록에 범위를 벗어난 값이 있으면 직접 수정하거나 지운 뒤 저장합니다.

큰 글씨에서는 입력칸을 세로로 배치합니다. 사용자 매뉴얼과 앱 도움말의 설명·이미지도 직접 입력 방식에 맞췄습니다.

## 업데이트 방법

Android 11(API 30) 이상을 지원합니다. 기존 앱을 삭제하지 않고 APK를 덮어 설치해 주세요. 업데이트 전에 **설정 → 데이터 내보내기·가져오기**에서 전체 데이터를 보관할 수 있습니다. DB 스키마는 9를 유지합니다.
