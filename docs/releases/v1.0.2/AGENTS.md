## v1.0.2 Android 15 호환 수정

화면 재생성 후 Android 15에서 키보드 위에 하단 탭이 남는 문제를 수정했습니다. API 35에서 기존 CI와 같은 오류를 재현한 뒤 동일 검사를 통과시켰습니다. 버전 코드는 3이며 앱 ID·서명·DB 스키마·백업 형식은 유지합니다.

| 검사 | 결과 |
| --- | --- |
| 계산·저장소 단위 검사 | 25개 통과, 실패·건너뜀 0 |
| Lint | 오류 0, 경고 20, 힌트 1 |
| API 35 회전·키보드 | 수정 전 실패 재현 → 수정 후 기본/큰 글씨 각 1개 통과 |
| API 36 회전·키보드 회귀 | 기본/큰 글씨 각 1개 통과 |
| API 35 실제 프로세스 복구 | PID 6144→6407, 미저장 입력 복구·버리기 통과 |
| v1.0.1→v1.0.2 업데이트 | 서명 동일, 덮어 설치 성공. 치료·사용·감사 이력 각 1행을 포함한 모든 DB 행 동일 |
| 원격 전체 CI | [최종 소스 실행](https://github.com/poyal/perilog/actions/runs/36836418353) 성공. 단위·Lint·API 35 기본/큰 글씨 E2E 각 15개·프로세스 복구 모두 통과 |

업데이트 검사는 새로 만든 API 35 에뮬레이터에 v1.0.1 출시 APK를 설치하고 UI로 가상 63.2kg 기록을 저장한 뒤 진행했습니다. 실제 사용자 자료는 사용하지 않았습니다. 결과와 DB 비교 자료는 `.tools/upgrade-v102/`에 보관합니다.

- 수정 소스: `fb37d21`, v1.0.2 버전 반영: `dfcd045`.
- APK: `dist/perilog-1.0.2.apk`, 5,141,258바이트.
- APK SHA-256: `e7e58dd67b64d2f17c223509d13fb4eebab6884b0fe8db38180e791ec82aeaea`.
- 스크린샷 ZIP: 기본 UI 23장과 API 35 가로·큰 글씨·키보드 1장, 총 24장.
- ZIP SHA-256: `c2e1a2f73a428cfa449732465686e39e68013fc146873a9cd5d0af14659ef734`.
- README의 기본 23장은 v1.0.1 신규 UI 촬영분이며 UI 구성이 같은 v1.0.2에서도 사용합니다. 24번 이미지는 업데이트한 v1.0.2 서명 APK에서 직접 촬영했습니다. Android 15의 가로·1.5배 글씨에서 키보드 표시·입력값·저장 버튼·하단 탭 숨김을 확인했습니다.
