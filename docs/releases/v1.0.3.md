# 페리로그 v1.0.3

기록 입력과 조회 화면을 간결하게 정리하고 사용 구성 이름과 대표 색상으로 사용 내역을 구분합니다. 버전 코드는 4입니다.

- 오늘의 기록을 활력 상태·사용 구성·투석 기록으로 표시하고, 치료 입력 화면의 각 카드에 단계 숫자와 입력 완료 색상을 표시합니다.
- 숫자 입력의 증감 퀵 버튼을 제거하고 제수량 계산 설명을 ? 도움말로 옮겼습니다.
- 기록 카드의 구성 이름 태그를 누르면 상세 물품을 확인합니다. 수정·삭제는 오른쪽 ⋮ 메뉴에서, 사용 취소는 구성 상세에서 실행합니다.
- 사용 구성별 대표 색상을 정하고 관리 목록·구성 선택·선택된 구성·기록 태그와 상세에 함께 표시합니다.
- 조회 기간·투석 종류·완료 상태를 선택 상자로 정리했습니다.
- 혈압·체중·초기배액량·기계 제수량을 한 줄에 하나씩 라인차트로 표시합니다.
- 어제의 기록은 미입력 단계만 표시하고 제목 옆에 시계 아이콘과 날짜를 배치했습니다.

Room 스키마는 1→2→3으로 이전하여 구성 이름·색상 정보를 추가합니다. 기존 기록·사용 내역·재고·초안과 이전 JSON 백업을 유지합니다. 예전 기록은 품목과 수량이 같은 등록 구성의 이름을 표시합니다.

## 설치

`perilog-1.0.3.apk`를 내려받아 기존 앱 위에 설치하세요. v1.0.0~v1.0.2와 같은 앱 ID와 서명 키를 사용하므로 앱을 삭제할 필요가 없습니다. Android 12 이상을 지원합니다.

## 검증

- [GitHub Actions](https://github.com/poyal/perilog/actions/runs/36872414699)의 단위·Lint·기본/큰 글씨 E2E·프로세스 복구 검사가 모두 통과했습니다.
- 로컬 단위·저장소 검사 29개 통과, Lint 오류 0. API 31·35에서 Room 1→3 이전 후 기록·사용 내역·초안·구성 보존을 확인했습니다.
- Android 15의 v1.0.2 서명 APK에 가상 기록을 저장하고 v1.0.3으로 덮어 설치했습니다. DB 버전이 1→3으로 올라가고 기존 행과 필드 값이 보존됨을 확인했습니다.
- APK 서명이 기존 릴리즈와 일치합니다. 버전 코드는 4이며 JSON 백업 형식은 유지합니다.
