# 페리로그 v1.0.5

병원 일정과 연락처를 홈에서 확인하고, 재고 입고·사용·추가·손실 이력을 한곳에서 관리할 수 있습니다.

## 주요 변경

- 병원 일정: 진료과별 예약시간과 색상, 여러 치료 항목의 아이콘, 날짜·메모와 D-day를 표시합니다. 자주 쓰는 진료과·치료 항목을 등록하고 다음 예약에 재사용합니다.
- 연락처: 이모지 아바타와 전화·문자 허용을 설정합니다. 홈에서 연락처를 누르면 연결 방법을 선택합니다.
- 재고: 품목의 ⋯에서 현재 수량 맞추기 또는 사유를 적어 일부 수량을 추가·차감합니다. EA는 수량 옆에 표시합니다.
- 통합 이력: 입고·사용·추가·손실·수량 맞추기를 종류·상태·품목·기간으로 조회하고 잘못 입력한 내역을 취소합니다.
- 기록 삭제: 연결된 물품 사용을 함께 취소합니다. 삭제 직후 되돌리기로 기록과 사용 상태를 복구할 수 있습니다.
- 기록 화면: 제목 오른쪽 +에서 새 기록을 추가합니다. 신규 기록의 측정값과 사용 구성은 빈 상태로 시작합니다.
- 캘린더: 일요일부터 표시하고 일요일은 빨강, 토요일은 파랑으로 구분합니다.
- 통계: 투석 결과를 총 제수량 하나로 표시합니다. 완료 항목은 체크로 구분합니다.
- 사용기한 입력·안내와 미배정 안내를 제거했습니다. 재고는 입고 순서로 차감하며, 예전 백업의 사용기한 값은 호환용으로 보존합니다.

병원 예약 알림은 제공하지 않습니다. 기존 미작성 기록 알림은 설정에서 사용할 수 있습니다.

## 설치와 데이터 보존

Android 12 이상에서 `perilog-1.0.5.apk`를 내려받아 **기존 앱 위에 설치**하세요. 버전 코드는 6입니다. 업데이트 전에 설정에서 전체 데이터를 내보내 두세요. 앱을 삭제하거나 데이터를 초기화하지 마세요.

기록 삭제 후에도 사용 내역을 남겼던 이전 버전의 자료는 자동 취소하지 않습니다. 잘못된 사용만 기록 화면이나 재고 이력에서 취소하세요. 수량 맞추기 이후의 현재 재고는 직접 확인한 기준을 따르므로 그보다 이전 사용을 취소해도 새 기준 수량에 다시 더하지 않습니다.
