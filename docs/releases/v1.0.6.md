# 페리로그 v1.0.6

날짜 선택과 메모 표시를 다듬고, 새 연락처 등록이 기존 연락처에 영향을 주지 않도록 저장 흐름을 보완했습니다.

## 주요 변경

- 병원 일정 등 날짜 선택 달력에서 일곱 요일이 화면 너비 안에 모두 표시됩니다. 달력 내부의 가로 스크롤을 없앴습니다.
- 투석 기록에만 오늘·어제 날짜 바로가기를 남기고, 다른 날짜 입력은 달력에서 선택하도록 정리했습니다.
- 통계에서 투석 기록을 위쪽, 활력 상태를 아래쪽에 표시합니다. 조회 기간의 날짜를 더 크고 굵게 표시합니다.
- 투석 기록·병원 일정·품목·재고 이력의 메모를 제목과 배경이 있는 블록으로 표시합니다. 긴 메모는 더 보기·접기로 확인하며, 기록 메모는 카드 안쪽 너비를 채웁니다.
- 더 보기·접기는 본문보다 작은 글씨와 간결한 버튼 영역으로 표시합니다.
- 투석 기록의 시작·종료 시각 입력을 제거했습니다. 기존 기록과 백업에 저장된 시각은 보존합니다.
- 연락처를 연속 등록하거나 수정 후 새로 등록할 때 입력 상태를 각각 분리합니다. 새 등록이 기존 연락처를 덮어쓰지 않도록 저장 단계에서도 확인합니다.

## 설치와 데이터 보존

Android 12 이상에서 `perilog-1.0.6.apk`를 내려받아 **기존 앱 위에 설치**하세요. 버전 코드는 7입니다. 업데이트 전에 설정에서 전체 데이터를 내보내 두세요. 앱을 삭제하거나 데이터를 초기화하지 마세요.

## 검증

- 전체 단위·저장소 82개, Android 15 기본·1.5배 화면 검사 각각 34개 통과.
- Android 16 입력·회전·키보드 검사 기본·1.5배 각각 통과. 실제 프로세스 종료 후 초안 복구 확인.
- 최종 서명 APK 신규 설치와 v1.0.5 위에 덮어 설치 확인. 기존 14개 테이블·34행·323개 필드와 재고·연락처·일정·메모·권한·백업 보존 확인.
- Lint 오류 0. Galaxy Z 플립7의 접기·펼치기, 삼성 키보드·파일 선택기·생체 인증·장시간 절전은 별도 실기기 확인 범위입니다.
