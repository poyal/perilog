# 페리로그 v1.0.7

통계 도표와 기록 표를 보기 쉽게 바꾸고, 기간 선택·연락처 입력·버튼 표시를 통일했습니다.

## 주요 변경

- 통계의 표 선택을 항목별 도표로 바꿨습니다. 총 제수량은 막대, 혈압은 수축기·이완기 연결 도표, 체중은 점그래프로 확인하며 라인차트도 사용할 수 있습니다.
- 기록 표를 전체화면으로 열고 두 손가락이나 − / + 버튼으로 25~200% 확대·축소합니다. 전체 열 맞춤, 고정 제목·날짜 열, 셀 상세와 기록 열기를 지원합니다.
- 통계·기록·재고 이력에서 시작일과 종료일을 함께 고르는 기간 선택기를 사용합니다. 기간 지정에서만 날짜 범위 버튼이 활성화됩니다.
- 기록 목록의 ‘기록 삭제 후 유지한 사용 내역’ 보조 영역을 제거했습니다. 기록 삭제 시 연결된 사용도 취소하는 기존 동작과 저장 데이터는 유지합니다.
- 연락처 번호의 하이픈을 자동 표시합니다. `15771111`, `1577 1111`, `1577-1111` 입력을 모두 처리하고 `114` 같은 짧은 번호도 저장합니다.
- 아웃라인 버튼에 흰색 배경을 적용하고 취소·저장 등 동작 버튼의 모서리·높이·여백을 통일했습니다. 다크 모드에서는 테마에 맞는 배경을 사용합니다.

## 설치와 데이터 보존

Android 12 이상에서 `perilog-1.0.7.apk`를 내려받아 **기존 앱 위에 설치**하세요. 버전 코드는 8입니다. 업데이트 전에 설정에서 전체 데이터를 내보내 두세요. 앱을 삭제하거나 데이터를 초기화하지 마세요.

## 검증

- 전체 단위·저장소 92개, Android 15 기본·1.5배 화면 검사 각각 39개 통과.
- Android 16 회전·키보드·전화번호 입력 검사 기본·1.5배 각각 3개 통과. 실제 프로세스 종료 후 초안 복구 확인.
- 최종 서명 APK 신규 설치와 v1.0.6 위에 덮어 설치 확인. 기존 14개 테이블·36행·337개 필드 및 재고·권한·백업 보존.
- Lint 오류 0. Galaxy Z 플립7 실물의 접기·펼치기, 삼성 키보드·파일 선택기·생체 인증·장시간 절전은 별도 확인 범위입니다.
