# v1.0.8 변경 내용

## 입고 요청 계산기

병원 방문일과 다음 방문일 사이에 필요한 물품을 최근 사용 기록 또는 직접 정한 사용 구성으로 계산합니다. 기록이 없을 때도 품목별 사용량을 입력할 수 있고, 주당 구성 비율·중간 변경일·여유분·방문일 잔량·최종 요청량을 조정할 수 있습니다. 요청안 저장·복사·공유와 나누어 받은 물품의 실제 입고를 지원합니다. 요청 저장 자체로는 재고가 늘지 않습니다.

## 홈 화면 위젯

어제·오늘 기록을 홈과 같은 세 단계로 표시합니다. 기본 4×2에서 2×2 또는 한 칸 높이 4×1로 조절할 수 있습니다. 병원 일정 2×2는 D-day·진료과별 시간·모든 처치를 보여 줍니다. 홈 앱의 실제 크기에 맞춰 배치·글씨·간격을 바꾸며 라이트·다크·앱 잠금·기록과 예약 이동을 지원합니다. 절전 상태에서는 갱신이 지연될 수 있고 항목이 많으면 크기를 늘려야 읽기 편합니다.

## 연락처와 앱 사용 안내

연락처 순서를 바꾸고 홈에도 같은 순서를 적용합니다. 등록·순서 변경 버튼을 나란히 배치하고 수정·삭제는 세로 ⋮ 메뉴에서 엽니다. 각 화면의 ?와 설정의 사용 안내에서 검색·실제 화면 확대·오프라인 설명을 이용할 수 있습니다. README와 앱 안내에 계산기·분할 입고·연락처·위젯 조절 방법을 반영하고 위젯 개발 가이드를 추가했습니다.

## 업데이트

기존 앱을 삭제하지 않고 같은 서명의 APK를 덮어 설치합니다. Room 7→8은 기존 자료를 보존하고 입고 요청 테이블 및 입고 연결 필드를 추가합니다. 연락처 순서와 요청안은 백업·복원에 포함됩니다. 업데이트 전 전체 데이터 내보내기를 권장합니다.

## 검증

- 전체 단위·저장소 133개, Android 15 전체 UI 기본 55개·1.5배 55개 통과.
- Android 16 입력·계산기·위젯 회귀 기본·1.5배 각각 19개, Android 12 실제 위젯 10개 통과.
- 실제 프로세스 종료 후 초안 복구, 최종 서명 APK 신규 설치와 v1.0.7 덮어 설치 확인. 기존 14개 테이블·36행·337개 필드 및 재고·백업·권한 보존.
- Lint 오류 0. 앱 안내 18개 주제와 실제 화면 39장을 점검했습니다.
- Galaxy Z 플립7 실물의 삼성 홈·접기/펼치기·생체 인증·장시간 절전은 별도 확인 범위입니다.
