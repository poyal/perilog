# v1.0.9 변경 내용

## 입고 요청에 여유분 추가

계산된 기본 요청량에 공통 여유 일수와 품목별 추가 EA를 더할 수 있습니다. 재고가 충분해 기본 요청량이 0이어도 여유분을 요청할 수 있으며, 최종 수량을 직접 지정한 값은 유지됩니다. 이전에 저장한 요청은 기존 계산을 유지하고 새 방식으로 전환할 때 확인할 수 있습니다.

## 병원 일정과 예약일 기준 재고

홈의 병원 일정 카드를 누르면 해당 예약의 상세가 열립니다. 날짜·진료과별 시간·치료·메모와 예약일 기준 재고를 함께 보고 수정하거나 다음 예약에 재사용할 수 있습니다. 부족 예상·잔량 있음·잔량 0·미확인은 색상 칩으로 구분합니다. 홈에는 부족이 예상될 때만 다음 진료시간 옆에 경고 아이콘이 표시됩니다.

예상 사용량은 입고 요청 계산기와 같은 기준을 사용합니다. 기본은 최근 28일 중 확정 사용 기록이 있는 날의 평균이며, 기록 없는 날은 제외하고 같은 날 추가 사용은 합산합니다. 오늘 이미 사용한 양은 다시 빼지 않고 예약일 사용 전의 잔량을 예상합니다. 사용 구성이나 직접 사용량을 지정할 수도 있습니다. 아직 받지 않은 요청은 재고에 포함하지 않습니다.

## 기록 표와 병원 일정 위젯

기록 표의 확대·축소·전체 열·100%와 필터를 표 위에서 사용할 수 있습니다. 병원 일정 위젯이 화면을 끄거나 앱 프로세스가 다시 시작된 뒤 어제·오늘 기록 위젯으로 바뀌던 문제를 수정했습니다.

## 업데이트

기존 앱을 삭제하지 않고 같은 서명의 APK를 덮어 설치합니다. DB 스키마는 8을 유지하며 기존 기록·재고·초안·설정·예약·입고 요청을 보존합니다. 업데이트 전에 설정에서 전체 데이터를 내보내 두실 수 있습니다.

## 검증

전체 단위·저장소 143개, Android 15 기본·큰 글씨 UI 각각 59개, Android 16의 키보드·표·입고 요청·잔량 예측 회귀 각각 13개를 통과했습니다. 최종 서명 APK의 신규 설치와 v1.0.8 덮어 설치, 기록·재고·초안·설정·백업·권한 보존을 확인했습니다. Android 12·15·16에서 위젯의 프로세스 재시작·화면 꺼짐·시각 갱신·재부팅을 검사했습니다.

실물 Galaxy Z 플립7의 접기와 장시간 절전은 별도 확인 범위입니다. 자세한 출처와 결과는 [검증 기록](https://github.com/poyal/perilog/blob/main/docs/검증-기록.md)에 남겼습니다.
