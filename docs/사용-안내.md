# 설치와 사용

화면과 함께 따라 하려면 [사용자 매뉴얼](../README.md)을 참고하세요. 이 문서는 텍스트로 빠르게 확인하는 사용 안내이며, 전체 캡처는 [화면 안내](화면-안내.md)에 있습니다.

## 휴대폰 설치

1. [릴리즈](https://github.com/poyal/perilog/releases/latest)에서 해당 버전의 APK를 내려받아 휴대폰에서 엽니다.
2. Android가 요청하면 파일을 연 앱에 대해 ‘이 출처 허용’을 켭니다.
3. 설치 후 ‘페리로그’를 엽니다.
4. 업데이트할 때는 같은 서명으로 만든 APK를 기존 앱 위에 설치합니다. 앱을 삭제하고 설치하면 내부 기록이 지워지므로 먼저 내보내기를 실행하세요.

## 앱에서 업데이트하기

1. 설정 → **업데이트**에서 업데이트 확인을 누릅니다. 앱을 완전히 종료하고 새로 시작할 때도 새 버전을 안내합니다. 다른 앱에서 돌아오거나 화면을 회전할 때는 반복하지 않습니다.
2. **버전 번호가 붙은 APK 다운로드**를 누르면 브라우저 없이 Download 폴더에 저장합니다. 다운로드 진행률을 확인하고 취소하거나 실패 후 다시 시도할 수 있습니다.
   예전 APK만 받은 경우에는 최신 버전의 첫 다운로드 버튼이 표시됩니다. 진행률·파일 이름·설치 버튼은 최신 확인 버전의 파일에만 연결되며, 이전 파일·진행 중인 이전 다운로드는 자동 삭제·취소하지 않습니다.
3. 다운로드가 끝나면 APK 체크섬을 확인합니다. 검증에 실패한 파일은 앱에서 설치하지 않으며 다시 다운로드해야 합니다.
4. **같은 버전의 업데이트 설치**를 누릅니다. 출처 허용 설정이 필요하면 Android 화면에서 허용한 뒤 돌아와 설치를 다시 누릅니다. 최종 설치는 Android 확인 화면에서 진행합니다.
5. 설치 실패·취소·보안 차단 후에도 APK는 Download 폴더에 남습니다. **다운로드 폴더 열기** 또는 ‘내 파일 → 다운로드’에서 직접 열 수 있습니다. 성공 후에도 자동 삭제하지 않습니다.

자동 조회는 24시간 간격이며 수동 확인은 별도로 가능합니다. 인터넷이 없으면 마지막 확인 정보와 시각을 표시하고 기록 입력·저장은 계속 사용할 수 있습니다. GitHub에는 업데이트 조회·다운로드 요청만 보내며 기록·백업을 전송하지 않습니다.

앱을 삭제하거나 데이터를 초기화하지 말고 기존 앱 위에 설치하세요. 업데이트 전 전체 데이터 내보내기를 권장합니다.

업데이트 기능이 없는 예전 앱은 [최신 릴리즈](https://github.com/poyal/perilog/releases/latest)에서 APK를 내려받아 기존 앱 위에 설치합니다.

## 앱 안에서 사용법 찾기

화면 오른쪽 위 **?**를 누르면 관련 설명과 실제 화면이 열립니다. **설정 → 사용 안내**에서 전체 목차를 보거나 검색할 수 있습니다. 인터넷 없이 열리며, 이미지를 누르면 두 손가락으로 확대할 수 있습니다. 뒤로 돌아오면 작성하던 값을 이어서 입력합니다. 제수량 옆 **?**는 해당 기록의 계산식 안내입니다.

## 처음 한 번

1. 재고 → 품목 관리에서 사용하는 투석액, 카세트, 손투석 라인 등을 등록합니다. 제품명에 농도·용량을 적고 색상을 고릅니다.
2. 이미 보유한 물품은 **재고 → 품목의 ⋮ → 수량 맞추기**에 실제 EA를 입력하고 저장합니다. 받은 날짜별로 등록하려면 일괄 입고를 이용합니다.
3. 설정 → 사용 구성 또는 재고 → 사용 구성 관리에서 자주 사용하는 조합을 저장합니다.
4. 설정에서 이전 주입 설정값을 확인합니다. 기본은 2000mL입니다.
5. 설정 → 자동 백업에서 휴대폰의 보관 폴더를 선택합니다. 기본은 매일, 최근 자동 백업 30개입니다.

## 매일 기록

홈에서 오늘 기록을 시작하고 몸무게·혈압을 입력합니다. 신규 기계투석·추가투석 기록은 이전 측정값이나 사용 구성을 가져오지 않고 빈 상태로 시작합니다. 사용 구성에 표시된 버튼을 눌러 이번에 사용한 구성을 고르고 품목·수량을 확인합니다. 기존 기록이나 초안을 이어 쓰면 입력했던 내용이 유지됩니다. 홈과 기록 입력 화면에서 완료 항목은 체크, 미완료 항목은 빈 원으로 표시합니다.

활력 상태 오른쪽 **저장 아이콘**을 누르면 요약으로 접히고, **수정 아이콘**으로 다시 펼칩니다. 입력값은 초안으로 보관되며 전체 기록은 화면 아래 **기록 저장**으로 저장합니다.

시작 전만 입력해 저장해도 됩니다. 투석이 끝나면 홈의 이어쓰기로 초기배액량과 **기계 제수량**을 입력합니다. ‘총 제수량’은 앱이 계산합니다. **평균저류시간 · 메모 추가**에서 선택 항목을 입력할 수 있습니다. 시작·종료 시각과 1~4차 배액은 따로 입력하지 않습니다.

손투석은 기록 화면 제목 오른쪽의 + → 추가투석 기록 추가에서 사용 구성만 저장해도 완료됩니다. 하루 여러 건을 기록할 수 있습니다. 배액량이나 배액무게를 적을 때 단위를 확인하세요. kg 입력은 소수 셋째 자리까지 저장됩니다. 무게를 부피로 바꾸거나 용기 무게를 자동 차감하지 않습니다.

가로 화면에서 키보드 때문에 높이가 부족하면 제목 영역이 잠시 접힙니다. 키보드를 닫으면 제목과 뒤로 버튼이 돌아옵니다.

## 총 제수량과 입력 단위

앱은 `초기배액량 − 이전 최종 주입 설정값 + 기계 제수량`으로 총 제수량을 계산합니다. 예를 들어 `2300 − 2000 + 600 = 900mL`입니다. 실제 최종 주입량을 자동으로 읽는 기능은 없으며, 저장한 설정값을 기준으로 표시합니다.

통계의 기간 버튼에서 시작·종료 날짜를 확인합니다. 위쪽에는 투석 기록, 아래쪽에는 혈압·몸무게의 활력 상태를 표시합니다. **표시 방식**은 기본 **라인차트**와 **항목별 도표** 중 선택합니다. 항목별 도표는 총 제수량 막대그래프, 수축기·이완기를 한 쌍으로 연결한 혈압 도표, 체중 점그래프입니다. 도표나 **날짜별 값 확인**을 누르면 값과 **기록 열기**가 나타납니다. 계산할 수 없는 기록은 평균에서 제외하고 값 확인에는 —로 표시합니다. 같은 날짜의 기록은 각각 확인할 수 있습니다.

통계·기록·재고 이력에서 **기간 지정**을 선택하면 시작일과 종료일을 한 달력에서 고릅니다. **적용**을 눌러 조회를 바꾸며, 양 끝 날짜를 모두 포함합니다. 취소하면 이전 조회 기간을 유지합니다. **기간 지정** 상태에서만 기간 버튼을 눌러 다시 선택할 수 있습니다. **7D·30D·90D**에서는 날짜 범위만 표시합니다. 선택기에서는 날짜 직접 입력으로 전환할 수 있습니다.

투석 기록·병원 일정·품목·재고 이력의 메모는 **메모** 제목이 있는 블록으로 표시합니다. 긴 내용은 세 줄로 줄이며 **더 보기**와 **접기**로 전체 내용을 확인할 수 있습니다.

제수량 옆 **?**에서 계산식과 해당 기록의 기준을 확인·수정합니다. 설정의 기준을 바꿔도 이미 저장한 과거 기록의 기준은 유지됩니다. 음수는 **제수량 + / − 바꾸기**, 측정값 0은 `0`으로 입력합니다. 빈칸은 미입력으로 남습니다.

## 기간별 표

**기록 → 표**는 전용 전체화면으로 열립니다. **필터**에서 기본 7일, 30일, 전체 또는 지정 기간과 투석 종류·완료 상태를 선택합니다. 첫 화면은 전체 열을 너비에 맞추며, 두 손가락 또는 **− / +**로 확대·축소합니다. **전체 열**과 **100%로**로 배율을 빠르게 바꿀 수 있습니다. 제목 행과 날짜·유형 열을 고정한 채 상하·좌우로 이동합니다. 셀을 누르면 아래에 전체 값이 나타나고 **기록 열기**로 해당 기록을 엽니다. 복귀·화면 회전 시 배율과 위치를 유지합니다. 추가투석은 같은 날짜라도 각각 한 행이고 배액 단위는 그대로 표시합니다.

표의 필터·축소·확대·전체 열·100%로는 표 바로 위에 고정됩니다. 셀을 선택하면 하단에서 전체 값을 확인하고 기록을 열 수 있습니다.

## 날짜·수정·삭제

- 기록 캘린더와 날짜 선택 달력은 일요일부터 시작합니다. 토요일은 파란색, 일요일은 빨간색으로 표시합니다.
- 투석 기록의 날짜 선택에는 **오늘·어제** 바로가기가 있습니다. 병원 일정·입고·재고 조정 등 다른 화면에서는 **날짜 선택**을 눌러 달력에서 고릅니다. 날짜 선택 달력은 좌우로 밀지 않아도 일곱 요일이 모두 보입니다.
- 날짜는 오늘이 기본이며 어제 또는 과거 날짜를 선택할 수 있습니다. 자정을 지나도 선택한 날짜를 유지합니다. 아침에 어제 시작한 기록을 이어 쓰면 어제 날짜에 저장됩니다. 홈 위쪽의 어제 기록 안내를 사용하세요.
- 입력 중 나간 내용은 초안으로 보관됩니다. 초안과 구성 미리보기만으로 재고를 차감하지 않습니다.
- 저장한 사용량을 바꾸면 차이만 반영합니다. 종료 후 수치만 추가하거나 다시 저장해도 재고를 다시 차감하지 않습니다.
- 기록 삭제는 연결된 물품 사용도 함께 취소해 재고에 반영합니다. 삭제 직후 **되돌리기**는 기록과 삭제 전 사용 상태를 함께 복구합니다. 이미 취소한 사용과 초안 삭제는 수량을 다시 더하지 않습니다.

## 입고 요청 계산과 분할 입고

1. **재고** 아래쪽 관리 메뉴에서 **입고 요청 계산기 → 새 입고 요청 계산**을 엽니다. 위쪽 이번 방문일과 아래쪽 다음 방문일을 고르면 각 달력이 전체 너비로 펼쳐집니다. 이번 방문일부터 다음 방문일 전날까지 계산합니다.
2. 기본 참고 기간은 어제까지 28일입니다. 확정한 실제 사용량을 평균 내며 기록 없는 날은 제외합니다. 참고한 일수를 확인하세요.
3. 기록이 없거나 사용이 달라지면 **평소 사용 바꾸기**를 엽니다. **사용 구성**에서 기본 구성과 다른 구성의 주당 일수를 정하면 기본 구성의 나머지 일수가 자동으로 맞춰집니다. **품목별 직접 입력**에서는 하루·일주일 수량을 적습니다. 추가 사용은 주당 횟수로 더할 수 있습니다.
4. **참고 기간 · 사용 변경**에서는 특정 날짜부터 달라질 사용을 정합니다. **여유분 더 받기**에서 없음·3일·7일 또는 직접 일수를 선택하고 **이 품목만 더 받기**로 개별 EA를 추가합니다. 기본 요청이 0이어도 여유분은 추가되며, 중간값을 유지하고 최종 합계만 올림합니다. 여유 일수 기본값은 0일이고 주간 일수는 요일 고정 없이 비율로 계산합니다.
5. 현재 재고에서 방문 전 사용량을 뺀 **방문일 예상 재고**와 최종 요청량을 확인합니다. 미등록 재고는 보유량을 빼지 않은 필요량으로 표시하며, 방문 전 부족은 따로 표시합니다. 중간값은 그대로 두고 최종 EA만 올림합니다.
6. **방문일 잔량 직접 입력·실제 요청할 수량**으로 조정하고 **요청안 저장**을 누릅니다. 잔량은 **잔량 보정 해제**, 최종 수량은 **자동 계산값 적용**으로 각각 되돌립니다. 최종 수량을 직접 지정하면 여유 일수를 바꿔도 지정값을 유지하며, 자동 계산값을 적용해야 개별 추가분을 다시 바꿀 수 있습니다. 요청만 저장하면 재고가 늘지 않습니다.
7. 저장한 요청에서 복사·공유·수정할 수 있습니다. 방문일까지 새로운 계산과 비교해 **새 계산 적용**을 누르면 직접 입력한 요청량은 유지합니다. 이미 입고한 내역이 있으면 저장한 계산 기준을 유지합니다.
8. 실제 받았을 때 **물품 받았어요**에서 날짜와 받은 품목을 체크하고 실제 수량을 고쳐 **받은 수량 저장**을 누릅니다. 나누어 받으면 같은 요청에서 반복합니다. 요청·받은 양·남은 양·초과분이 표시되며, 연결된 입고의 수정·취소도 반영합니다.

## 물품 입고와 재고

한 번에 들어온 제품은 입고 등록에서 입고일·품목별 EA 수량·메모를 함께 저장합니다. 빈칸·0EA는 제외하며 사용기한은 관리하지 않습니다.

재고는 입고 순서로 자동 차감합니다. 이번 기록만 수량 조정에서 실제 사용 재고를 직접 지정할 수도 있습니다.

재고가 모자라도 치료 기록은 저장되며 부족한 수량은 음수로 표시됩니다. 누락한 입고를 실제 날짜로 보완하거나 현재 수량을 확인하세요. 미등록 수량은 0EA로 표시하지 않습니다.

**품목의 ⋮ → 수량 맞추기**는 새로운 실사 기준을 만듭니다. 기준일 이전의 기록은 해당 수량에서 다시 차감하지 않으며 이전 사용을 취소해도 새 기준 수량에 다시 더하지 않습니다.

일부 개수만 바꾸려면 **품목의 ⋮ → 수량 추가·차감**에서 **차감 · 손실** 또는 **추가**, 변경일, 수량, 필수 사유를 입력합니다. **적용 후 현재 재고**를 확인하고 **조정 저장 → 확인**을 누릅니다. 1~100,000EA를 입력할 수 있으며 저장 전에는 재고가 바뀌지 않습니다. **재고 → 이력** 또는 **재고 상세 → 이 품목 이력**에서 사유와 수량을 보고 잘못된 조정을 취소할 수 있습니다. 취소한 내역도 남습니다. 과거 조정 이후 수량을 맞춘 이력이 있으면 현재 재고는 그 기준을 따릅니다.

**재고 → 이력**은 입고·사용·추가·손실·수량 맞추기를 통합합니다. 필터 첫 줄은 종류·상태, 둘째 줄은 품목·기간입니다. 기간은 전체/7D/30D/직접 지정이며, 수정·조회 화면에 다녀와도 필터를 유지합니다. 입고·추가는 +, 사용·손실은 −, 실사는 기준 수량으로 표시합니다. 입고 수정·취소, 연결된 기록 보기·사용 취소, 조정 취소를 이 화면에서 실행합니다. 입고 취소는 같은 입고의 모든 품목에 적용됩니다. 품목 상세의 **이 품목 이력**은 해당 품목을 미리 선택합니다.

## 백업과 복원

- 내보내기: 기록·초안·계산 기준·품목·구성·재고·입고 요청과 연결된 입고·설정을 JSON 파일로 저장합니다.
- 가져오기: 파일 검증 및 요약을 확인한 후 **전체 교체**합니다. 합치기는 하지 않습니다. 실제 사용량을 다시 차감하지 않습니다.
- 복원·초기화 직전 데이터는 앱 내부 보호 백업에 남습니다. 설정에서 외부로 내보낼 수 있습니다. 앱 삭제 시 내부 보호 백업도 삭제됩니다.
- 자동 백업은 새 파일 검증이 끝난 후 오래된 자동 파일만 정리합니다. 사용자가 내보낸 파일과 보호 백업은 자동 삭제하지 않습니다.
- 백업 파일은 암호화하지 않습니다. 앱 잠금·화면 보호는 백업 파일까지 보호하지 않습니다.
- 새 기기 또는 재설치 후에는 백업 폴더를 다시 선택해야 합니다. 폴더 접근 실패·최근 성공 시각은 설정에서 확인합니다.

## 캘린더 연동

**설정 → 병원·연락처 → 캘린더 연동**에서 **휴대폰 캘린더 연결** 또는 **구글 계정으로 연결**을 선택합니다. 권한을 허용하고 쓰기 가능한 캘린더 하나를 고른 뒤 전송 내용을 확인하고 **연동 시작**을 누릅니다. 구글 직접 연결에는 배포자의 [Google Cloud 설정](구글-캘린더-연결-준비.md)이 필요합니다.

- 처음에는 오늘 이후 예약을 보내고, 이후 페리로그에서 등록·수정·삭제한 예약을 자동 반영합니다. 이미 연결된 과거 예약도 수정·삭제를 반영합니다.
- 방문 하나를 일정 하나로 표시합니다. 진료과가 여러 개면 제목은 **병원 방문 · 심장과 외 1개**처럼 첫 진료과와 나머지 개수로 줄이고, 전체 진료과·검사·치료 항목은 설명에 담습니다. 시작은 가장 이른 지정 시간, 표시용 종료는 마지막 지정 시간의 30분 뒤입니다. **예약 메모 포함**은 기본으로 꺼져 있으며 최초 연결 시간대를 유지합니다. 이미 전송한 일정의 제목도 바꾸려면 **전체 다시 반영**을 누릅니다.
- 캘린더에서 수정·삭제하거나 새로 만든 내용은 페리로그에 가져오지 않습니다. 페리로그에서 예약을 다시 수정하거나 **전체 다시 반영**하면 앱 내용으로 덮어쓰고 외부에서 삭제된 일정은 다시 생성합니다.
- **지금 동기화**는 대기 작업을 재시도합니다. 휴대폰 방식의 완료는 기기 저장 완료이며 구글 웹 반영까지의 완료를 뜻하지 않습니다. 오프라인이어도 앱 예약은 저장되고, 구글 전송은 인터넷 연결 후 재시도합니다.
- **연결 해제**는 외부 일정을 남기는 것이 기본입니다. **페리로그가 보낸 일정도 삭제**를 선택하면 연결한 일정만 정리합니다. 캘린더 변경 시 기존 일정을 남기면 중복 여부를 확인하세요.
- 복원·초기화하면 외부 일정은 그대로 두고 연동을 일시 정지합니다. 연결 정보·대기 작업은 JSON 백업에 포함하지 않습니다. 새 기기의 휴대폰 캘린더는 기존 일정을 확인·정리한 후 새 전송에 동의해야 합니다.

## 병원 일정과 연락처

홈의 **병원 일정 카드**를 누르면 해당 예약의 상세가 열립니다. **설정 → 병원 일정**의 관리 화면도 같은 예약 카드와 메뉴를 사용합니다. 날짜·진료과별 시간·치료 항목·메모와 **예약일 기준 재고**를 확인하고, 카드 오른쪽 위 **⋮ 더보기**에서 **일정 수정**, **같은 구성으로 다음 예약**, **일정 삭제**를 선택합니다. 삭제는 확인창에서 **확인**을 눌러야 적용됩니다. 제목 옆 **+**는 새 예약 등록, 부족 경고 아이콘은 잔량 계산 상세로 바로 연결됩니다.

홈은 부족이 예상될 때만 다음 일정 시각 옆에 **경고 아이콘**을 표시합니다. 아이콘을 누르면 예상 잔량 상세가 열립니다. 재고가 충분하거나 예상 잔량이 0인 경우, 사용량·재고가 미확인인 경우에는 아이콘을 표시하지 않습니다. **설정 → 병원 일정**의 **예약일 기준 재고**에서는 부족 예상·잔량 있음·잔량 0·미확인을 각각 빨강·초록·주황·회색 칩으로 구분합니다. 품목별 예상 수량도 같은 색으로 표시하며 부족 품목을 먼저 보여 줍니다. **예상 잔량 계산 보기**는 현재 재고·하루 평균 사용량·계산 기간·예상 사용량·잔량을 품목별로 보여 줍니다. 어제까지 최근 28일 중 확정 사용 기록이 있는 날짜로 평균을 내며, 추가 사용을 합산하고 기록 없는 날을 0으로 넣지 않습니다. 입고 요청 계산기와 같은 사용량 계산을 사용합니다.

오늘 이미 기록한 사용은 다시 빼지 않고 방문 전날까지의 사용을 예상합니다. 오늘 방문은 현재 재고를 표시하며, 실제 입고·사용·취소·조정과 날짜 변경에 따라 갱신됩니다. 미수령 요청은 재고에 포함하지 않습니다. 정확히 0인 잔량·부족·재고 미등록·사용 근거 없음을 구분합니다. **평소 사용 바꾸기**에서 구성·주간 비율·직접 사용량을 지정하면 **지정한 사용 구성대로라면**으로 표시하고 병원 일정 전체에 적용합니다. 실제 재고와 저장한 입고 요청은 바뀌지 않으며 위젯에는 예상 재고를 표시하지 않습니다.

설정의 **병원·연락처** 구역에서 관련 메뉴를 바로 엽니다. **진료과**에서는 이름과 색상을, **검사·치료 항목 → + 치료 항목 등록**에서는 치료 항목 하나의 이름·아이콘을 저장합니다. 병원명은 입력하지 않으며 진료과와 치료 항목은 독립적으로 관리합니다.

홈의 **병원 일정 등록** 버튼에서 새 예약을 등록합니다. 예정 일정이 있으면 제목 옆 **+**를 사용합니다. 예약일을 지정하고 진료과를 여러 개 선택한 뒤 각 진료과의 예약시간을 입력하거나 **시간 선택**을 이용합니다. 선택한 모든 진료과의 시간이 필요하며, 진료과를 선택하지 않으면 공통 예약시간을 입력합니다. 치료 항목은 여러 개 선택하고, 시간이 필요한 항목만 **시간 지정**을 누릅니다. 지정한 시간은 수정·해제할 수 있고 메모는 선택입니다. 저장하면 가장 가까운 예정 예약의 D-N 또는 당일 D-day 옆에 날짜와 다음 일정 시각을 작은 글씨로 표시합니다. **색상 · 진료과 이름 · 예약시간**을 한 태그에 표시하고 시간순으로 정렬하며 치료 아이콘도 이어집니다. 공간이 부족하면 다음 줄로 내려갑니다. 저장한 일정은 홈의 상세에서 수정할 수 있으며, 전체 일정의 수정·삭제는 **설정 → 병원 일정**에서 합니다. 첫 진료시간이 지나도 남은 진료가 있으면 계속 표시되고, 마지막 진료·치료 시간이 지나면 다음 일정으로 바뀌며 이전 예약은 **지난 일정**에 남습니다. 예약 알림은 제공하지 않습니다.

**같은 구성으로 다음 예약**은 진료과·치료 항목을 가져오고 날짜·진료과별 시간·메모는 새로 입력하게 합니다. 작성 중 등록·관리 화면에 다녀와도 입력을 유지합니다. 원본 진료과·치료 항목을 수정·삭제해도 기존 예약은 보존되며, 수정 내용을 가져오려면 예약에서 해제 후 다시 선택합니다. 이전 묶음 구성의 치료 항목들도 개별 항목으로 이어서 사용할 수 있습니다. 예전 공통 예약시간은 각 진료과에 표시하며 편집에서 개별 변경합니다.

설정 → **연락처 → + 연락처 등록**에서 이모지 아바타·이름·번호를 입력하고 전화·문자 허용을 각각 설정합니다. 처음에는 빈 목록이며 연락처가 없을 때만 홈의 **연락처 등록** 버튼에서 입력 화면을 바로 열 수 있습니다. 저장한 연락처는 홈의 **연락처**에 한 줄 최대 3개씩 표시됩니다. 아바타를 누르면 **연결 방법 선택** 모달에 허용한 전화·문자 버튼을 표시하고, 둘 다 끄면 연결이 꺼졌다는 안내를 표시합니다. 실제 통화·전송은 해당 앱에서 직접 실행합니다. 수정·삭제는 **설정 → 연락처 → 연락처 오른쪽 ⋮** 메뉴에서 합니다. 삭제는 확인창에서 확인을 눌러야 적용됩니다.

전화번호는 숫자만 입력해도 번호 형식에 맞게 하이픈을 표시합니다. `15771111`, `1577 1111`, `1577-1111`은 모두 `1577-1111`로 표시·저장합니다. 공백·하이픈을 포함한 붙여넣기를 지원하며, `114`·`112`·`119`처럼 짧은 번호는 그대로 입력·저장합니다.

진료과·검사·치료 항목·일정·연락처도 전체 백업·복원과 초기화에 포함됩니다.

연락처가 두 개 이상이면 **설정 → 연락처 → 순서 변경**에서 위·아래 화살표로 옮긴 뒤 **순서 저장**을 누르세요. 관리 목록과 홈에 함께 적용되며 **취소**하면 기존 순서를 유지합니다. 새 연락처는 마지막에 추가되고, 저장한 순서도 백업·복원에 포함됩니다.

## 휴대폰 홈 위젯

**설정 → 홈 화면 위젯**에서 **기록 위젯 2×2 추가·4×2 추가** 또는 **일정 위젯 추가**를 누르고 홈 화면에 배치하세요. 휴대폰 홈의 빈 곳을 길게 눌러 **위젯 → 페리로그**에서도 추가할 수 있습니다. 위젯을 길게 눌러 크기를 조절하거나 삭제합니다.

- **어제·오늘 기록:** 기본 4×2와 높이를 한 칸으로 줄인 4×1은 좌우 카드이며 폭을 줄인 2×2에서는 위아래로 표시합니다. 높이가 넉넉하면 각 카드의 단계를 펼치고 4×1처럼 낮으면 세 단계를 가로로 표시합니다. 활력 상태·사용 구성·투석 기록의 완료는 파란 체크, 미완료는 빈 원으로 표시합니다. 날짜를 누르면 해당 기록·초안, 제목은 앱 홈을 엽니다. 추가투석만 미완료라면 추가투석으로 연결하며, 열기만으로 사용량을 확정하지 않습니다.
- **병원 일정:** 기본 2×2에서 가장 가까운 방문의 D-day·날짜·진료과별 시간·처치를 모두 표시합니다. 길쭉하면 처치를 한 열로, 낮거나 항목이 많으면 두 열로 배치합니다. 메모는 제외합니다. 오늘은 D-day이며 마지막 진료·치료 시간 후 다음 방문으로 바뀝니다. 일정 영역은 수정, 제목은 전체 일정, 빈 일정 안내는 새 예약을 엽니다.
- **크기·갱신·잠금:** 같은 격자 크기라도 홈 앱에 따라 모양이 달라집니다. 위젯 글씨는 휴대폰 글씨 배율보다 위젯 공간에 맞춥니다. 스크롤·생략 없이 배치·글씨·간격을 공간에 맞추며 작게 보이면 위젯을 늘려 주세요. 앱 변경과 오른쪽 위 새로고침으로 갱신합니다. 절전 상태에서는 지연될 수 있습니다. 앱의 라이트·다크 설정을 따르며 앱 잠금과 관계없이 위젯 내용은 표시되며 앱으로 이동할 때 인증합니다.

## 알림과 잠금·화면 보호

홈 미작성 안내는 항상 제공합니다. Android 13 이상에서는 알림 권한이 없으면 첫 실행에 OS 권한 창이 표시됩니다. Android 12에서는 시스템 알림 설정을 바로 사용합니다. 이후 **시스템 알림 설정 열기**에서 허용·소리·진동을 관리하고, 앱에서 시각을 지정한 뒤 **알림 시각 저장**을 누릅니다. 완료한 날에는 보내지 않으며 절전 상태에 따라 지연될 수 있습니다. 생체 인증·기기 잠금은 선택 기능입니다.

설정 → **화면·표시**에서 테마를 고르고 **화면 설정 저장**을 누릅니다. **앱 잠금·화면 보호**에서 두 옵션을 각각 선택한 뒤 **잠금·보호 설정 저장**을 누릅니다. 저장 버튼은 화면 아래에 고정되며, 저장 결과는 상태 표시줄 아래에 잠시 내려와 표시됩니다. 안내가 떠도 본문과 버튼은 움직이지 않습니다. 기록 삭제 후 **되돌리기**도 상단 안내에서 누릅니다. 저장 전 나가면 변경사항을 버릴지 확인합니다. 앱 잠금을 켜려면 휴대폰에 생체 인증이나 화면 잠금이 먼저 설정되어 있어야 합니다.

- **앱 잠금:** 앱을 열거나 다른 앱에서 돌아올 때 인증합니다. 이것만 켜면 캡처·녹화는 가능합니다.
- **화면 보호:** 스크린샷·화면 녹화·공유를 막고 최근 앱 미리보기를 가립니다. 앱 잠금 없이도 켤 수 있습니다. 캡처가 필요하면 끄고 저장하세요.
- 처음 설치하면 둘 다 꺼져 있습니다. 기존 잠금 사용자는 업데이트 후 두 옵션이 켜진 상태로 유지되며 이후 각각 변경할 수 있습니다.
- 두 옵션은 홈 화면 위젯 내용과 앱 밖에 저장한 백업 파일에는 적용되지 않습니다.

## 설정 목록

설정 첫 화면은 **일반 → 투석 기록·물품 → 병원·연락처 → 백업·데이터 → 도움말·앱 정보** 순서입니다. 각 구역의 항목이 한 목록에 펼쳐져 있습니다. 스크롤해 원하는 항목을 누르면 바로 상세 화면으로 이동합니다.

- **일반:** 화면·표시, 알림, 앱 잠금·화면 보호, 홈 화면 위젯.
- **백업·데이터:** 자동 백업, 데이터 내보내기·가져오기, 보호 백업, 데이터 초기화. 초기화는 마지막 별도 화면에서 확인 후 진행합니다.
- **투석 기록·물품:** 사용 구성, 품목 관리, 투석 계산 기준, 사용자 색상.
- **병원·연락처:** 병원 일정, 진료과, 검사·치료 항목, 연락처.
- **도움말·앱 정보:** 사용 안내, 업데이트, 앱 정보·문의. 업데이트와 제작자·문의 화면은 분리되어 있습니다.
