# 캘린더 연동 개발 검증

최종 단위 검사는 총 95건, 실패·오류 0건입니다. 최종 검토에서 일광 절약 시간 전환 때 표시용 종료를 실제 30분 뒤로 계산하도록 보완하고, 구글의 삭제된 ID가 410 응답을 반환하는 경우도 처리했습니다. 이 변경은 관련 단위 검사 재실행으로 확인했습니다.

로컬 로그는 Git 제외 경로 `.tools/calendar-final-checks.log`, `.tools/calendar-ui.log`, `.tools/calendar-ui-large.log`, `.tools/calendar-permission.log`에 있습니다. Gradle 보고서는 `app/build/test-results/testDebugUnitTest`와 `app/build/reports/androidTests/connected/debug`에 생성됩니다. 이 경로는 재검사 때 갱신될 수 있습니다.

초기 UI 검사는 샘플 getter가 매번 다른 `createdAt`을 만든 탓에 비교 1건이 실패했습니다. 샘플을 고정한 후 같은 검사 3건을 재실행하여 모두 통과했습니다. 실패한 결과를 통과로 집계하지 않았습니다.

## 재실행

```sh
./scripts/build.sh :app:testDebugUnitTest \
  --tests 'com.poyal.perilog.CalendarSyncTest' \
  --tests 'com.poyal.perilog.GoogleCalendarTest' \
  --tests 'com.poyal.perilog.RepositoryTest' \
  --tests 'com.poyal.perilog.AppointmentTest' \
  --tests 'com.poyal.perilog.GuideTest' \
  :app:lintDebug :app:assembleDebug

ANDROID_SERIAL=emulator-5580 ./scripts/build.sh :app:connectedDebugAndroidTest \
  '-Pandroid.testInstrumentationRunnerArguments.class=com.poyal.perilog.CalendarFlowTest,com.poyal.perilog.SettingsFlowTest#allSettingsOpenDirectlyAndBackRestoresTheListWithoutChangingData' \
  -Pandroid.injected.androidTest.leaveApksInstalledAfterRun=true
```

UI 검사는 **초기화 가능한 전용 에뮬레이터**에서만 실행합니다. 샘플 앱 데이터를 복원하고, `LOCAL` 계정의 검사 전용 캘린더를 생성·삭제합니다. 사용자의 실제 계정 캘린더나 진료 자료를 사용하지 않습니다.

큰 글씨 검사는 에뮬레이터의 `font_scale`을 1.5로 설정하고 `CalendarFlowTest`와 위 SettingsFlowTest 메서드를 실행한 뒤 1.0으로 복원했습니다. 권한 거절 검사는 별도 실행이며, 시작 전에 테스트 앱의 두 권한을 해제해야 합니다. `scripts/test-e2e.sh`의 기본 검사에는 CalendarFlowTest를 포함하고, 아래 검사는 별도로 실행합니다.

```sh
.tools/android-sdk/platform-tools/adb -s emulator-5580 shell pm revoke com.poyal.perilog.debug android.permission.READ_CALENDAR
.tools/android-sdk/platform-tools/adb -s emulator-5580 shell pm revoke com.poyal.perilog.debug android.permission.WRITE_CALENDAR
.tools/android-sdk/platform-tools/adb -s emulator-5580 shell am instrument -w \
  -e class com.poyal.perilog.CalendarPermissionFlowTest \
  com.poyal.perilog.debug.test/com.poyal.perilog.PerilogTestRunner
```

## 2026-10-07 제목·화면 보완 검사

- 외부 일정 제목을 첫 진료과와 나머지 개수로 줄였습니다. 전체 진료과·시간은 설명에 유지하며, 기존 CalendarSyncTest에서 진료과 0·1·2·3개를 확인했습니다. 26건 모두 통과했습니다.
- 선택 버튼의 이름·계정을 중앙 정렬하고 아이콘·이동 화살표를 추가했습니다. 연결 확인창은 캘린더 정보·전송 내용·기존 일정 확인을 구분하고 체크 항목 간격과 누를 수 있는 영역을 넓혔습니다.
- 수정 후 debug 앱·검사용 APK 빌드와 lintDebug가 통과했습니다. 별도 API 35 테스트 에뮬레이터에서 `CalendarFlowTest#connectThroughSettingsAndKeepLocalAppointmentAuthoritative`를 기본·1.5배 글씨로 각각 실행하여 각 1건 통과했습니다. 축약 제목으로 등록·수정·재전송·삭제하는 흐름과 확인창 스크롤을 검사했습니다.
- 로그: `.tools/calendar-polish-checks.log`, `.tools/calendar-spacing-checks.log`, `.tools/calendar-polish-ui.log`, `.tools/calendar-polish-ui-large.log`. 선택 화면과 확인창 캡처는 `.tools/calendar-polish-captures/`에 보관했습니다. 실제 계정 대신 검사 전용 로컬 캘린더를 사용했습니다.

## 실제 서비스 검증의 남은 항목

- Google Cloud 프로젝트가 아직 없으므로 실제 OAuth 로그인, 구글 Calendar API 전송과 구글 웹 반영은 **미검증**입니다. [설정 준비 안내](구글-캘린더-연결-준비.md)에 따라 등록 후 검사해야 합니다.
- 구글 계정의 휴대폰 동기화 어댑터와 삼성 기기·삼성 캘린더에서 연결 식별자가 유지되는지는 **미검증**입니다. API 35의 로컬 Calendar Provider 검사를 제조사·계정별 검사로 대신하지 않습니다.
- 이번 검사는 개발 변경에 대한 검사입니다. 서명 릴리즈 APK의 덮어 설치·전체 릴리즈 검사는 실행하지 않았으며 게시도 하지 않았습니다.
