# 화면 안내

[사용자 매뉴얼](../README.md) · [텍스트 사용 안내](사용-안내.md) · [화면 원본 다운로드](https://github.com/poyal/perilog/releases/latest)

기능별 실제 화면을 모았습니다. 가상 데이터를 사용했으며 제품 구성과 수치는 사용법을 설명하기 위한 예시입니다. 이미지를 누르면 원본을 볼 수 있습니다.

<details>
<summary>화면 촬영 정보</summary>

2026-10-03에 v1.0.6 기준으로 촬영한 화면입니다. 병원 일정·연락처·메모·재고 조정·통합 이력은 가상 자료이며 실제 연락처와 사용자 기록을 사용하지 않았습니다. API 35 개발 빌드와 API 36 최종 서명 APK를 사용했습니다. 개발 빌드의 업데이트 상태는 검사 응답을 사용한 예시입니다. 가로 입력 화면은 글씨 1.5배이며, 나머지는 기본 글씨입니다.

통계(10·11·45), 전체화면 기록 표(23·44), 기간 선택기(43)는 같은 날의 개선 작업 개발 빌드(API 35)에서 새로 촬영했습니다. 공개된 v1.0.6의 화면과는 차이가 있습니다.

취소·이력·백업·연락처 연결 등 아웃라인 버튼과 선택 버튼의 흰색 배경을 반영한 화면 30장도 같은 날 API 35 개발 빌드에서 다시 촬영했습니다. 이후 취소·저장 등 동작 버튼의 둥근 사각형 모양·높이·여백을 통일한 화면으로 갱신했습니다. 다크 모드에서는 어두운 채움색을 사용하며, 선택된 항목은 강조색으로 구분합니다.

</details>
