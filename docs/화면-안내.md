## 입고 요청 계산기

재고 아래쪽 관리 메뉴에서 **품목 관리 · 색상** 위의 **입고 요청 계산기**를 열어 방문 사이의 필요량을 계산합니다. 기록이 없을 때도 기본·다른 구성의 주당 일수나 직접 사용량으로 계산하며, 예상 잔량과 실제 요청량을 조정할 수 있습니다. 요청 저장만으로 재고가 바뀌지는 않습니다.

**이번 방문일·다음 방문일**은 위아래 두 줄로 배치합니다. 각 항목의 **날짜 선택**을 누르면 달력이 전체 너비로 펼쳐져 일곱 요일과 두 자리 날짜를 확인할 수 있습니다.

**여유분 더 받기**에서 공통 일수를 정하고, 품목별 **이 품목만 더 받기**에서 EA를 추가합니다. 기본 필요량이 0이어도 선택한 여유분을 더하며, 직접 지정한 최종 수량은 **자동 계산값 적용** 전까지 유지합니다.

## 병원 일정과 연락처

홈의 병원 일정 카드를 누르면 해당 예약의 상세가 열립니다. 날짜·진료과별 시간·치료·메모와 재고 요약을 확인하고 일정 수정·다음 예약·삭제로 이어갈 수 있습니다. **설정 → 병원 일정**에서도 같은 카드를 사용합니다. 카드 오른쪽 위 **⋮ 더보기**에서 수정·다음 예약·삭제를 고릅니다. 삭제는 확인창에서 확정합니다.

홈에서는 부족 예상이 있을 때만 다음 진료시간 옆의 **경고 아이콘**을 표시하며, 누르면 예상 잔량 상세가 열립니다. 충분·0·미확인 상태는 홈에서 표시하지 않습니다. 예정 일정 관리의 **예약일 기준 재고**에서는 부족 예상은 빨강, 잔량 있음은 초록, 잔량 0은 주황, 미확인은 회색 칩으로 구분합니다. 품목별 예상 수량도 색상 칩에 표시하며 부족 품목을 먼저 보여 줍니다. **예상 잔량 계산 보기**는 최근 28일 중 확정 사용 기록이 있는 날짜의 평균으로 방문 전날까지의 잔량을 보여줍니다. 오늘 이미 기록한 사용은 다시 빼지 않고, 아직 받지 않은 요청은 재고에 더하지 않습니다. 직접 사용 구성을 지정하면 **지정한 사용 구성대로라면**으로 표시합니다.
