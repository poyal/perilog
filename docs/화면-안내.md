# 화면 안내

[사용자 매뉴얼](../README.md) · [텍스트 사용 안내](사용-안내.md) · [화면 원본 다운로드](https://github.com/poyal/perilog/releases/latest)

기능별 실제 화면을 모았습니다. 가상 데이터를 사용했으며 제품 구성과 수치는 사용법을 설명하기 위한 예시입니다. 이미지를 누르면 원본을 볼 수 있습니다.

<details>
<summary>화면 촬영 정보</summary>

2026-10-03에 v1.0.5 기준으로 39장을 촬영했습니다. API 35 개발 빌드 37장과 API 36 최종 서명 APK의 가로 입력·설정 토글 화면 2장입니다. 병원 일정·연락처·재고 조정·통합 이력은 가상 자료이며 실제 연락처와 사용자 기록을 사용하지 않았습니다. 개발 빌드의 업데이트 상태는 검사 응답을 사용한 예시입니다. 가로 입력 화면은 글씨 1.5배이며, 나머지는 기본 글씨입니다.

</details>
