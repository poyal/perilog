# 나의 하루, 나의 투석 기록 v1.0.0

개인용 복막투석 기록 앱의 첫 설치 버전입니다. Android 12 이상에서 사용하며, 로그인·외부 API·인터넷 권한 없이 휴대폰 내부에 기록을 보관합니다.

## 설치 파일

- **perilog-1.0.0.apk**: 휴대폰에 직접 설치하는 서명된 APK
- **perilog-1.0.0.sha256**: APK와 스크린샷 ZIP의 SHA-256 체크섬
- **perilog-1.0.0-screenshots.zip**: Android 16 에뮬레이터에서 실제 실행한 화면 20장. 예시 데이터로 촬영했습니다.

휴대폰에서 APK를 다운로드하고 열어 설치하세요. 업데이트는 기존 앱 위에 설치합니다. 앱 삭제·기기 변경 전에는 설정에서 데이터를 파일로 내보내세요.

**[이미지로 보는 사용자 매뉴얼](https://github.com/poyal/perilog/blob/v1.0.0/README.md)**

## 포함된 기능

- 시작 전 몸무게·혈압, 종료 후 초기배액량·기계 제수량 기록과 총 제수량 계산
- 직전 실제 사용 구성·입력값 참고, 숫자 증감, 과거 날짜와 초안 보관
- 하루 여러 번 추가투석, 물품 사용만 저장하거나 배액무게·배액량 선택 입력
- 품목 색상과 컬러 피커, 사용 템플릿, EA 재고, 날짜별 일괄 입고·이력·사용기한 임박 안내
- 홈의 미입력 안내와 완료 표시, 기록 목록·달력, 기간별 그래프·표
- JSON 전체 내보내기·복원, 폴더 자동 백업, 선택형 로컬 알림·앱 잠금, 밝은/어두운 테마

총 제수량은 `초기배액량 − 이전 최종 주입 설정값 + 기계 제수량`입니다. 이전 주입 기준의 기본값은 2000mL이며 실제 최종 주입량을 매일 확인하기 어려운 사용 방식을 반영했습니다. 백업 가져오기는 전체 교체이며 JSON 파일 자체는 암호화하지 않습니다.

## 확인한 범위

도메인 12개·저장소 8개·에뮬레이터 UI 5개 테스트 통과, Lint 오류 없음. 서명 APK의 서명 검증·업데이트 설치·콜드 실행을 확인했습니다. 문서용 화면 20장의 자동 촬영도 완료했습니다.

실물 Z 플립7의 접기·펼치기, 삼성 파일 선택기, 생체 인증, 절전 상태에서의 백업·알림은 별도 확인 대상입니다. 자세한 결과는 [검증 기록](https://github.com/poyal/perilog/blob/v1.0.0/readme/검증-기록.md)에 있습니다.
