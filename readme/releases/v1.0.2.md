# 페리로그 v1.0.2

Android 15에서 화면 회전·재생성 후 키보드를 열면 하단 탭이 남아 입력 공간을 차지하던 문제를 수정했습니다. 기존 기록과 재고는 그대로 유지됩니다.

- 창의 키보드 영역 처리를 초기화하는 순서를 보완했습니다.
- 기본 글씨와 1.5배 글씨에서 회전·입력값 유지·저장 버튼 표시를 검사합니다.
- CI 에뮬레이터의 화면 꺼짐·잠금을 방지하고, 실제 프로세스 종료 후 미저장 입력 복구 검사를 보완했습니다.

## 설치

`perilog-1.0.2.apk`를 내려받아 설치하세요. 기존 v1.0.0·v1.0.1 사용자는 앱을 삭제하지 않고 덮어 설치합니다. 동일한 앱 ID와 서명을 사용하며 데이터베이스·백업 형식은 변경하지 않았습니다.

Android 12 이상에서 사용할 수 있습니다. 외부 API·로그인·인터넷 권한 없이 휴대폰 안에 기록을 저장합니다.

## 사용 설명과 화면

[사용자 매뉴얼](https://github.com/poyal/perilog#readme)에서 기록·구성·재고·백업 사용법을 확인하세요. 매뉴얼의 23장은 v1.0.1 신규 UI를 Android 16 에뮬레이터에서 촬영한 화면이며 v1.0.2에서도 같은 구성을 사용합니다. 예시 자료로 촬영했습니다.

첨부한 스크린샷 ZIP에는 매뉴얼 23장과 Android 15의 큰 글씨·가로·키보드 수정 확인 화면을 포함합니다.

## 검증

[전체 CI](https://github.com/poyal/perilog/actions/runs/36836418353)에서 단위 검사·Lint·API 35 기본/큰 글씨 E2E 각 15개·실제 프로세스 복구가 모두 통과했습니다. 로컬 단위·저장소 25개와 API 35·36 회전 검사를 통과했고 Lint 오류는 0입니다.

v1.0.1에 저장한 가상 기록을 v1.0.2로 덮어 설치한 뒤 모든 DB 행이 동일함을 확인했습니다. Android 15 큰 글씨·가로 키보드 추가 화면은 배포하는 서명 APK로 직접 촬영했습니다.

Galaxy Z 플립7 실기기에서 접기·펼치기, 삼성 키보드·시스템 파일 선택기·생체 인증은 별도 확인 대상입니다.
