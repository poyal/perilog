# 페리로그 v1.0.4

다크모드의 가독성을 높이고 앱 안에서 새 버전을 확인·다운로드·설치할 수 있게 했습니다.

- 남색 배경과 카드 구분, 밝은 본문·보조 설명, 선명한 입력칸 테두리와 하늘색 주요 버튼.
- 설정 항목의 설명과 토글을 좌우로 정렬하고 구분선을 추가했습니다. 항목 전체를 눌러 전환할 수 있습니다.
- 설정 → **페리로그 정보**: 버전·제작자·문의·GitHub·업데이트 확인.
- 새 버전이 있으면 앱 프로세스가 새로 시작될 때 안내. 자동 조회는 하루 한 번, 수동 확인 가능.
- 브라우저 없이 APK 다운로드 → 체크섬 검증 → Android 설치 화면 연결.
- 설치 실패·취소·보안 차단 후에도 Download 폴더의 APK를 보존하고 파일 앱에서 직접 열기 지원.
- 공개 전 설치 파일 재다운로드·해시 검증 및 중단된 업로드 재개.

기존 앱을 삭제하지 않고 동일 서명 APK로 업데이트하세요. 업데이트 전 설정에서 전체 데이터를 내보내 두실 수 있습니다. 기록 DB·백업 JSON 형식은 유지하며, GitHub에는 업데이트 조회·다운로드 요청만 보냅니다.

v1.0.3에서 덮어 설치하여 기록·재고·설정·백업 권한 보존을 확인했습니다. 검증 범위와 산출물 해시는 [검증 기록](https://github.com/poyal/perilog/blob/main/readme/검증-기록.md)을 참고하세요.
