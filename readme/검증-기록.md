# 페리로그 v1.0.1 검증 기록

검증일: 2026-10-01. 예시 자료와 개발용 패키지로 검사했습니다. APK 직접 설치 버전입니다. 사용자 요청에 따라 신규 UI 23장을 다시 촬영하고 v1.0.1 릴리즈를 게시했습니다. 공개 다운로드와 README도 확인했습니다.

## 확인한 사용자 흐름

- 기계 기록 → 총 제수량 900mL → 재고 10→8EA → 추가투석 물품만 저장 → 6EA
- 품목 등록, 일괄 입고, 입고 수량 수정·취소, 기한 기본 무관
- 템플릿 수량 지우기·재입력·증감, 이번 기록만 사용량 수정, 재저장 중복 차감 방지
- 품목 색을 바꾸면 구성 목록·편집·선택·선택된 칩에서 같은 색 표시
- 품목·구성·입고의 미저장 폼 재생성, 변경 버리기 확인, 저장 전 재고 불변
- 어제 기록에 아침 결과 입력 시 어제 날짜 유지, 완료 뒤 어제 안내 숨김
- 월·연도·윤년 경계의 어제 계산, 여러 미완료 기록, 미래 날짜 입력 차단
- 소수 입력 이어 쓰기, ±0.1/±0.5, 전체 지우기, 정수 수량 오류·복구
- 기간별 기록 표의 7D/30D/직접 기간, 기계/추가투석 행, 원래 배액 단위, 수정 후 선택 유지
- 초안 재생성·화면 회전, 설정 입력 복구·다크 모드, 통계 기간·표 유지
- 실제 파일 백업 내보내기·읽기·복원, 보호 파일 생성, 손상 파일 거절, v1.0.0 JSON 읽기

## 사용성 점검에서 수정한 내용

- `61.` 입력 중 소수점이 사라지던 문제: 사용자가 입력한 문자열과 계산값을 구분해 유지합니다.
- 구성 수량을 지우면 입력칸이 사라지던 문제: 선택 상태를 유지해 곧바로 다시 입력할 수 있습니다.
- 이전 저장 알림이 다음 화면의 저장 버튼을 가리던 문제: 화면 이동 시 이전 알림을 닫습니다.
- 키보드를 열 때 하단 탭이 입력 공간을 차지하던 문제: 키보드가 열린 동안 탭을 숨깁니다.
- 가로·큰 글씨·키보드 조합에서 입력칸 높이가 0이 되던 문제: 남은 화면 높이가 작으면 키보드가 열린 동안 제목 영역을 접고 입력칸과 저장 버튼을 유지합니다.
- 다크 모드 배경의 반투명 색이 아래로 갈수록 밝아지던 문제: 불투명 테마 색상끼리 보간합니다.
- 품목·구성·입고는 스크롤 본문과 고정 저장/취소 영역으로 나눕니다. 실제 촬영으로 색상·카드·숫자·배치도 점검했습니다.

## CI 안정화 재검증

[화면 유지 수정 후 원격 실행](https://github.com/poyal/perilog/actions/runs/36833694195)에서 단위 검사·Lint·프로세스 복구가 통과했습니다. UI 검사에는 Android 15의 재생성 후 키보드 처리 문제가 남아 별도로 수정했습니다. 최종 전체 CI 결과는 재확인 중입니다.

- SDK 설치·PATH를 명시하고 Android 설정 디렉터리를 `/tmp/perilog-android`로 통일했습니다. `sdkmanager` 미발견과 AVD 검색 경로 오류가 해소되어 원격 생성·검색·부팅이 통과했습니다.
- 이전 [원격 실행](https://github.com/poyal/perilog/actions/runs/36827803533)에서 단위 검사·Lint·기본/큰 글씨 오프라인 E2E가 통과했지만, 마지막 프로세스 복구는 `am kill` 직후 기존 PID가 남아 실패했습니다. Activity 중지·상태 저장 확인 후 개발용 앱의 PID를 직접 종료하고, 종료·새 PID·입력 복구를 각각 검사하도록 보완했습니다.
- 후속 실행의 `Portrait window focus` 실패와 앱 화면 미발견을 조사했습니다. 로컬 에뮬레이터에는 화면 유지 설정이 있었으나 CI에는 없었습니다. 로컬 화면을 끄면 UI 접근이 실패하고, 화면 유지·깨우기·잠금 해제 적용 후에는 같은 출발 조건에서 검사가 통과했습니다.
- 로컬 API 36 재현 결과: 기본/큰 글씨 회전 검사 각 1개 통과, 실패·건너뜀 0. 별도 프로세스 복구도 PID 20113→20322, 입력 복구·버리기 통과. 원래 화면 설정 복구를 확인했습니다.
- 화면 유지 수정까지는 CI·테스트·문서만 변경했습니다. 이후 아래 Android 15 호환 수정은 앱 코드에도 반영했습니다. 이미 게시한 v1.0.1 APK를 교체하지 않았습니다.

### Android 15 화면 재생성 후 키보드 회귀

- 로컬에 API 35 / Pixel 7 에뮬레이터를 추가해 원격의 `Portrait navigation hidden above keyboard` 오류를 동일하게 재현했습니다. 화면 켜짐·잠금 해제·창 포커스는 정상이며, 실제 캡처에서 키보드 위에 하단 탭이 남았습니다.
- 재사용되는 창의 content-insets 처리를 `enableEdgeToEdge()`가 decor view를 가져오기 전에 초기화하도록 했습니다. API 35의 상태 복원 경로에만 적용합니다. Android 15의 [PhoneWindow 구현](https://android.googlesource.com/platform/frameworks/base/+/android15-release/core/java/com/android/internal/policy/PhoneWindow.java)에서 edge-to-edge 강제 적용 이후에는 `setDecorFitsSystemWindows`가 바로 반환하는 점을 확인했습니다.
- 수정 전 API 35 회전 검사 1개 실패 → 수정 후 기본/큰 글씨 각 1개 통과, 실패·건너뜀 0. 같은 테스트 조건을 유지했고 큰 글씨·가로·키보드 캡처에서 입력값과 저장 버튼도 확인했습니다.
- 재현 산출물: `.tools/e2e-api35-before/`, `.tools/e2e-api35-after/`. API 36 회귀 결과는 `.tools/e2e-api36-regression/`에 보관합니다.
